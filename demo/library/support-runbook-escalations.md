# Support runbook — escalating an integration incident

1. **Confirm the scope.** Check the connector error rate and which workspaces are affected.
2. **Declare severity.** Use severity 1 if the error rate is above 10% for more than 15 minutes.
3. **Notify customers within 3 hours.** Use the incident template; include the start time and workaround status.
4. **Post to the status page.** One entry per incident; update every 30 minutes.
5. **Contact the partner.** Use the partner escalation contact; log the request time.
6. **After resolution.** Replay any queued data, confirm counts, and send a closing note.
7. **Review within 5 business days.** Record what we will change.
