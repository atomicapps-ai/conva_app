# Brightwater Labs — how we work

1. **Start with the floor.** We visit customers and watch the work before we design it.
2. **Make it work offline.** Our users do not control their connection.
3. **Write it down.** Decisions, handoffs and trade-offs are recorded where everyone can see them.
4. **Small squads, clear owners.** Every project has one named owner.
5. **Honest numbers.** We report results as measured, including when they are disappointing.
