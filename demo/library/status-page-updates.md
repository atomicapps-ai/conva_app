# Status page — Cedarline connector incident

**Resolved — 2 October, 08:10 PT.** Shipment-status updates from the Cedarline connector were delayed between 06:12 and 09:10 PT. All 1,860 queued updates have been replayed in order. No data was lost.

**Update — 07:30 PT.** A workaround is in place; the connector now accepts both authentication token formats. Updates are catching up.

**Identified — 07:05 PT.** The cause is a change to the authentication token format by our integration partner, made without advance notice.

**Investigating — 06:40 PT.** We are seeing elevated errors on the Cedarline connector.
