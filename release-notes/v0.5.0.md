## [0.5.0]

Conva conversations and preparation now travel with you: save a Context or a call as a portable file, hand it to another machine or a teammate, and pick up right where you left off.

### Highlights

- Export a Context — its setup, attached documents, and generated briefing/research/Q&A — or a saved conversation, with its reviewed claims and corrections, as a single portable `.cva` file. Import one back in on any install to recreate it, including on a fresh machine.
- The browser build can now build and download a Context's `.cva` archive, and bring one back in as a new Context — entirely client-side, no upload required to preview or export what's in an archive before importing it.

### Reliability

- Fixed the draft-release verification step always failing on a fresh release.
- Fixed the local web-preview server silently serving the wrong file for every request.
- Pinned line endings and now run Core's test suite on Windows CI as well.
