## [0.4.0]

Conva now turns important statements into source-aware conversation intelligence while making preparation and live use faster and easier to review.

### Highlights

- Review consequential claims detected during a conversation, including attribution, confidence, evidence status, and appropriate verification next steps.
- Set claim and source policies for interviews, company meetings, sales calls, live streams, and other high-stakes conversations.
- Prepare separate Research and Q&A resources, then compile their strongest material into one Context Intelligence Pack optimized for fast live retrieval.
- Keep the active question, complete Ally answer, and grounding sources together in the new Focus view; term definitions remain separate and generated documents are formatted and scrollable.
- Continue using Conva while Context resources regenerate—the research, LLM, file, and indexing pipeline now runs away from the window event loop.
- Download updates in the background, with an optional automatic-install setting that always waits for an active live session to finish.

### Experience and reliability

- Improved the startup progress sequence, narrow Context rows, compact navigation controls, profile avatar flow, and Conva brand mark.
- Added stricter release checks for substantive notes, signed updater artifacts, complete Windows and macOS assets, and a valid cross-platform update manifest.
